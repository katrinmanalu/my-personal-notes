# My Personal Notes

A personal notes app built with React for creating and managing notes.

## Features

* Create notes
* Search notes by title
* Archive notes
* Delete notes
* Character limit validation
* Responsive layout

## Technologies

* React
* JavaScript
* Vite
* CSS

## How to Run

Clone this repository and open the project folder.

Install the dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

The application will run locally at the address shown in the terminal.
